\title{Runspindle: The Case for Verified Work}\subtitle{Design scaffold; no live deployment or measured savings}\author{Runspindle}\date{November 2026}\begin{document}\begin{frame}\titlepage\end{frame}
\begin{frame}{The problem}\begin{itemize}
\item A tool call is not an accepted outcome.
\item Human repair, retries, and uncertain external effects belong in the cost.
\item A harness must preserve task authority rather than expand it.
\end{itemize}\end{frame}
\begin{frame}{The proposed system}\begin{itemize}
\item Core: Rust and Temporal. Host: native Codex.
\item Browser: OpenBao, PinchTab, KasmVNC. Tether: existing Slack integration.
\item Refinery: Python DSPy. Console: actual fleet views. Platform: distribution.
\item All new integrations remain scaffolded.
\end{itemize}\end{frame}
\begin{frame}{A measurable claim}\begin{itemize}
\item Compare native, expert-guided, and harness-assisted work on matched tasks.
\item Predeclare acceptance, authorization, failure, and stop rules.
\item Count every attempt and human intervention. No results are asserted.
\end{itemize}\end{frame}
\begin{frame}{Refinement with gates}\begin{itemize}
\item Select and authorize; review and redact; curate grouped held-out data.
\item Compare candidates on quality, safety, latency, and full cost.
\item Bind attributable reactions/replies to exact outputs; task-specific gold rules quarantine conflicts.
\item Gold eligibility is separate from human-approved candidate release and rollback.
\end{itemize}\end{frame}
\begin{frame}{Economics without a forecast}\begin{itemize}
\item Divide total operating cost by verified authorized completions.
\item Include setup, maintenance, verification, recovery, and failed attempts.
\item Low volume or provider improvements can erase a proposed advantage.
\end{itemize}\end{frame}
\begin{frame}{Next evidence}\begin{itemize}
\item Demonstrate a permissioned end-to-end task and uncertain-result recovery.
\item Verify component contracts before any production claim.
\item Historical source evidence is separate from Runspindle results. Source: SRC-002, SRC-013.
\end{itemize}\end{frame}

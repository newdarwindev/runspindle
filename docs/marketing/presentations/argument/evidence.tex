\begin{frame}[label=argument-evidence]{Evidence needed for the decision}
\begin{itemize}
\item Separate the effect of integration from the model, human assistance and task selection.
\item Exercise interruptions, recovery and independent acceptance on held-out services.
\item Compare quality, safety, latency and full cost after product upgrades.
\end{itemize}
\medskip
\href{https://github.com/newdarwindev/runspindle/blob/main/STATUS.json}{Current status}
records bounded synthetic and component evidence separately from blocked system acceptance.
The integrated system is not implemented; live acceptance is not run.

runtime behavior. Historical examples are not new Runspindle results.
\href{https://arxiv.org/abs/2407.01502}{Kapoor et al. (2024)} motivates joint cost,
quality and generalization checks. No comparative win is claimed.}
\end{frame}

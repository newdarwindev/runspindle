# Runspindle design adaptations

These are newly authored, concise adaptations of selected historical material, not faithful re-renders or migrated live applications. Historical source dependency closure is preserved privately. Overall selected-source migration remains partial.

- `runspindle-paper.pdf` and `.tex`: proposed system and evaluation argument.
- `argument.pdf`/`.tex`, `fleet.pdf`/`.tex`: two concise design decks.
- `workflow-refinery.pdf` and `.tex`: proposed DSPy evaluation and serving boundaries.
- `economics.md`: accepted-work cost accounting with no claimed savings.
- `index.html`, `browser.html`, `vision.html`: standalone product/design narratives.

The PDFs were generated with ReportLab, not compiled from TeX/Beamer. Their editable TeX sources are not compile-verified. See [BUILD.md](BUILD.md) for exact tools, reproduction commands and limits, and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for source rights.

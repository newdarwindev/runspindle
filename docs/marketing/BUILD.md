## Console-owned SRC-010 mirror

The vision page and its SRC-010 MIT notice, disposition map and validation record
are byte-preserved from the exact Console commit pinned in `artifacts.json`.
They are not generated by this script. Edit the canonical Console files first,
run its documented checks, then review and copy all four files together and update
the pinned canonical revision and hashes. No component Gitlink is advanced by this
document-only mirror. A local canonical pin does not prove publication or CI.

Before importing ReportLab or writing any generated artifact, `build_documents.py`
checks all four mirror hashes, canonical repository/path/revision, consistent pin,
required notice and blocked visual status. A missing, modified or mismatched
mirror fails without changing any existing generated output. The other document
rendering behavior and source notices remain unchanged. Check it from the root:

```
python3 -m unittest discover -s tests -p 'test_marketing_vision.py' -v
python3 tools/check_scaffold.py
python3 tools/check_artifacts.py
```

The tests generate only temporary copies. They verify the other outputs remain
byte-identical with the installed renderer and that negative preflight cases leave
all files untouched. Successful hash checks and builds do not pass responsive,
keyboard or actual browser zoom review. Those SRC-010 gates remain blocked as
described in `SRC-010-validation.md`; Console issue 2 remains open.

# Migration gates

The new repositories have fresh histories. This initial publication contains new stubs and selected-source specification adaptations, not a wholesale migration. Historical PDFs, paper dependencies, selected Python implementations and legacy Tether evidence still need complete review and adapted imports.

Before any legacy retirement: identify every repository's successor or explicit retirement, verify all required source/dependency/artifact preservation and rights, verify public/private separation, publish exact README and AGENTS deprecation links, disable Actions and reconcile pending runs, then archive and independently read back both settings. Do not unarchive already archived applications just to add notices.

Archiving a repository does not stop external services or sanitize its history. No archive or deprecation changes are part of this scaffold publication.
